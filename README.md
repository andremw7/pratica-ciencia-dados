# Projeto Estratificação ENEM

## 📌 Sobre o Projeto

Este projeto busca investigar a relação entre as condições socioeconômicas e educacionais das diferentes regiões brasileiras e o desempenho dos participantes do Exame Nacional do Ensino Médio (ENEM). A partir da análise de dados e indicadores relacionados à educação, à renda e às desigualdades regionais, pretende-se compreender de que maneira o contexto social e educacional pode estar associado às oportunidades e aos resultados obtidos pelos estudantes.

Partindo dessa ideia inicial, desenvolveremos uma análise crítica da problemática, buscando identificar padrões, desigualdades e possíveis relações entre os diferentes fatores observados. O planejamento e os direcionamentos do projeto poderão ser ajustados ao longo do desenvolvimento da pesquisa, conforme a análise dos dados e os novos questionamentos encontrados.educacional do país.
